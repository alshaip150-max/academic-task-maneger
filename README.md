# البوابة الجامعية التجريبية

بوابة عربية باتجاه RTL لإدارة التكليفات وتسليمات الطلاب ومراجعتها، مبنية كصفحات HTML/CSS/JavaScript ثابتة بلا خدمات خارجية.

## التشغيل

شغّل خادماً محلياً بسيطاً من مجلد المشروع:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`. صفحة الطالب هي `index.html` ولوحة المحاضر هي `admin.html`. صفحات `ACADIMIC/` القديمة تحوّل إلى الصفحات الموحدة في جذر المشروع.

## حدود النسخة التجريبية

- تحفظ الملفات والتكليفات والتسليمات في `localStorage` الخاص بهذا المتصفح فقط؛ لا توجد قاعدة بيانات مشتركة أو مزامنة بين أجهزة الطلاب.
- دخول الطالب ورمز التسجيل محليان تجريبيان وليسا مصادقة أو حماية للبيانات. لوحة المحاضر مفتوحة، ويمكن لأي مستخدم لهذا المتصفح مشاهدة البيانات أو تغييرها.
- لا تحفظ بيانات طلاب حقيقية ولا تعتمد على هذه النسخة للتقييم الفعلي. يلزم خادم موثوق مع مصادقة وتفويض وتخزين آمن قبل أي نشر إنتاجي.
